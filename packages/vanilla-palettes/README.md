# Vanilla Palettes

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/vanilla-palettes
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "vanilla-palettes"
      mode: "both"
```
