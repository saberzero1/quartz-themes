# Muted Blue

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/muted-blue
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "muted-blue"
      mode: "dark"
```
