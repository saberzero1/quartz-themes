# Big Bold

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: CC0-1.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/big-bold
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "big-bold"
        mode: "both"
```
