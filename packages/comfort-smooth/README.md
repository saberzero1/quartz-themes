# Comfort Smooth

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/comfort-smooth
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "comfort-smooth"
      mode: "dark"
```
