# Retronotes

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/retronotes
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "retronotes"
      mode: "both"
```

## Variants

- `retronotes.blueprint`
- `retronotes.carbon-ink`
- `retronotes.forest-green`
- `retronotes.misty-mirage`
- `retronotes.pinot-noir`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "retronotes"
      variation: "blueprint"
      mode: "both"
```
