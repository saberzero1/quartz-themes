# Theme That Shall Not Be Named

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/theme-that-shall-not-be-named
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "theme-that-shall-not-be-named"
      mode: "dark"
```
