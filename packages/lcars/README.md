# Lcars

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: NOASSERTION

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/lcars
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "lcars"
      mode: "dark"
```
