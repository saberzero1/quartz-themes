# Creature

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/creature
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "creature"
        mode: "dark"
```
