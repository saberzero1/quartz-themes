# Red Graphite

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/red-graphite
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "red-graphite"
      mode: "both"
```
