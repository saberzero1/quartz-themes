# Sanctum Reborn

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/sanctum-reborn
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "sanctum-reborn"
      mode: "both"
```

## Variants

- `sanctum-reborn.blue`
- `sanctum-reborn.cyan`
- `sanctum-reborn.green`
- `sanctum-reborn.lavender`
- `sanctum-reborn.orange`
- `sanctum-reborn.pink`
- `sanctum-reborn.pistachio`
- `sanctum-reborn.red`
- `sanctum-reborn.viridian`
- `sanctum-reborn.yellow`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "sanctum-reborn"
      variation: "blue"
      mode: "both"
```
