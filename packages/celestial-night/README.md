# Celestial Night

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/celestial-night
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "celestial-night"
      mode: "dark"
```
