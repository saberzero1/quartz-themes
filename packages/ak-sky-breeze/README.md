# Ak Sky Breeze

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/ak-sky-breeze
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "ak-sky-breeze"
      mode: "light"
```
