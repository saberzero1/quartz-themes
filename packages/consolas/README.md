# Consolas

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: Apache-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/consolas
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "consolas"
        mode: "dark"
```
