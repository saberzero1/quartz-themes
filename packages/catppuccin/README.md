# Catppuccin

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/catppuccin
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "catppuccin"
      mode: "both"
```

## Variants

- `catppuccin.frappe`
- `catppuccin.macchiato`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "catppuccin"
      variation: "frappe"
      mode: "both"
```
