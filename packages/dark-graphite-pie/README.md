# Dark Graphite Pie

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/dark-graphite-pie
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "dark-graphite-pie"
        mode: "both"
```
