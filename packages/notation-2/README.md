# Notation 2

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/notation-2
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "notation-2"
        mode: "both"
```
