# Fusion

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light and light
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/fusion
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "fusion"
      mode: "light"
```
