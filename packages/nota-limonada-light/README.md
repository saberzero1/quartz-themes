# Nota Limonada Light

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/nota-limonada-light
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "nota-limonada-light"
        mode: "light"
```
