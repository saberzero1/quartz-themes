# Tokyo Terminal Obsd

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: NOASSERTION

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/tokyo-terminal-obsd
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "tokyo-terminal-obsd"
      mode: "dark"
```
