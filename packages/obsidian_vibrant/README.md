# Obsidian_vibrant

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/obsidian_vibrant
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "obsidian_vibrant"
      mode: "dark"
```
