# Dissociated Identitea

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: AGPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/dissociated-identitea
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "dissociated-identitea"
      mode: "both"
```
