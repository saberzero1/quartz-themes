# Velocity

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/velocity
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "velocity"
      mode: "both"
```

## Variants

- `velocity.british-racing-green`
- `velocity.jet-black-matte`
- `velocity.midnight-purple`
- `velocity.nordblau-metalic`
- `velocity.obsidian-gray`
- `velocity.touring-bronze`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "velocity"
      variation: "british-racing-green"
      mode: "both"
```
