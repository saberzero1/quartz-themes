# Yin And Yang

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MPL-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/yin-and-yang
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "yin-and-yang"
      mode: "both"
```
