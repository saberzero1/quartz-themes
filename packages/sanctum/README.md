# Sanctum

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/sanctum
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "sanctum"
      mode: "both"
```

## Variants

- `sanctum.blue`
- `sanctum.cyan`
- `sanctum.green`
- `sanctum.lavender`
- `sanctum.orange`
- `sanctum.pink`
- `sanctum.pistachio`
- `sanctum.red`
- `sanctum.viridian`
- `sanctum.yellow`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "sanctum"
      variation: "blue"
      mode: "both"
```
