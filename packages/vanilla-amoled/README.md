# Vanilla Amoled

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: ISC

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/vanilla-amoled
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "vanilla-amoled"
        mode: "dark"
```
