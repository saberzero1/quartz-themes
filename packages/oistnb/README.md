# Oistnb

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Joke License

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/oistnb
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "oistnb"
        mode: "both"
```
