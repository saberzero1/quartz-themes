# Soli Deo Gloria

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: CC BY-SA 4.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/soli-deo-gloria
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "soli-deo-gloria"
        mode: "both"
```
