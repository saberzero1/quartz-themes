# Amethyst

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/amethyst
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "amethyst"
        mode: "both"
```
