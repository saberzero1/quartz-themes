# Lemons Theme

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/lemons-theme
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "lemons-theme"
        mode: "dark"
```
