# Retroma

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/retroma
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "retroma"
      mode: "both"
```

## Variants

- `retroma.analogous-reversed`
- `retroma.monochromatic`
- `retroma.monochromatic-reversed`
- `retroma.split-complementary`
- `retroma.split-complementary-reversed`
- `retroma.triadic`
- `retroma.triadic-reversed`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "retroma"
      variation: "analogous-reversed"
      mode: "both"
```
