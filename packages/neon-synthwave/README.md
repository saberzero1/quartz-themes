# Neon Synthwave

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: CC0-1.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/neon-synthwave
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "neon-synthwave"
      mode: "dark"
```
