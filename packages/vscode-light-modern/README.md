# Vscode Light Modern

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/vscode-light-modern
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "vscode-light-modern"
      mode: "light"
```
