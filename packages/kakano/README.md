# Kakano

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/kakano
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "kakano"
      mode: "both"
```

## Variants

- `kakano.black`
- `kakano.cyan`
- `kakano.green`
- `kakano.grey`
- `kakano.orange`
- `kakano.pink`
- `kakano.purple`
- `kakano.red`
- `kakano.white`
- `kakano.yellow`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "kakano"
      variation: "black"
      mode: "both"
```
