# Lizardmen Zettelkasten

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/lizardmen-zettelkasten
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "lizardmen-zettelkasten"
      mode: "dark"
```
