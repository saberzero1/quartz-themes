# Protocolblue

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: BSD 3-Clause

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/protocolblue
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "protocolblue"
      mode: "dark"
```
