# Hipstersmoothie

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/hipstersmoothie
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "hipstersmoothie"
      mode: "dark"
```
