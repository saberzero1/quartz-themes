# Obsidian Boom

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/obsidian-boom
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "obsidian-boom"
        mode: "light"
```
