# Its Theme

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: GPL-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/its-theme
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "its-theme"
      mode: "both"
```
