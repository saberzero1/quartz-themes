# Al Dente

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: CC0-1.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/al-dente
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "al-dente"
        mode: "light"
```
