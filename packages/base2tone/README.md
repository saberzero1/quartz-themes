# Base2tone

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/base2tone
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "base2tone"
        mode: "dark"
```
