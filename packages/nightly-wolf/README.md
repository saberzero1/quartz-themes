# Nightly Wolf

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/nightly-wolf
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "nightly-wolf"
        mode: "both"
```
