# Ukiyo

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/ukiyo
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "ukiyo"
        mode: "both"
```

## Variants

- `ukiyo.alchemy`
- `ukiyo.golden-book`
- `ukiyo.golden-coffee`
- `ukiyo.rose-shadow`
- `ukiyo.ukiyo`

```yaml
options:
  theme: "ukiyo"
  variation: "alchemy"
```
