# Buena Vista

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/buena-vista
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "buena-vista"
        mode: "both"
```
