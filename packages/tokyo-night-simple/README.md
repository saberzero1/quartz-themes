# Tokyo Night Simple

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/tokyo-night-simple
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "tokyo-night-simple"
      mode: "dark"
```
