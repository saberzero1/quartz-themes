# Auger

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: CC-BY-4.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/auger
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "auger"
      mode: "both"
```
