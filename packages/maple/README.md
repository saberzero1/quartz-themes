# Maple

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/maple
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "maple"
        mode: "both"
```

## Variants

- `maple.default`
- `maple.minimal`

```yaml
options:
  theme: "maple"
  variation: "default"
```
