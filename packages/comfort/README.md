# Comfort

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/comfort
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "comfort"
      mode: "light"
```
