# Esther Inspired

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: NOASSERTION

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/esther-inspired
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "esther-inspired"
      mode: "both"
```
