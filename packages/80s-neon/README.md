# 80s Neon

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: Unlicense

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/80s-neon
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "80s-neon"
      mode: "dark"
```
