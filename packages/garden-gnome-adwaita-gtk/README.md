# Garden Gnome Adwaita Gtk

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/garden-gnome-adwaita-gtk
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "garden-gnome-adwaita-gtk"
      mode: "both"
```
