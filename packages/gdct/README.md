# Gdct

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/gdct
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "gdct"
      mode: "light"
```
