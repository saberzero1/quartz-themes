# Green Holiday

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light and dark
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/green-holiday
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "green-holiday"
      mode: "both"
```
