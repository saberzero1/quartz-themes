# Tokyo Night Storm

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/tokyo-night-storm
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "tokyo-night-storm"
        mode: "dark"
```
