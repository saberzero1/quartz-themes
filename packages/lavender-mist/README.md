# Lavender Mist

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/lavender-mist
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "lavender-mist"
      mode: "light"
```
