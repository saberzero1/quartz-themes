# W95

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/w95
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "w95"
      mode: "light"
```
