# Rift

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: Joke License

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/rift
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "rift"
        mode: "dark"
```
