# Rmaki

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: GPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/rmaki
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "rmaki"
      mode: "dark"
```
