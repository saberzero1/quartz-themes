# Dynamic Color

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Apache-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/dynamic-color
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "dynamic-color"
        mode: "both"
```
