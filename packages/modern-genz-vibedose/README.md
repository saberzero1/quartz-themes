# Modern Genz Vibedose

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: AGPL-3.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/modern-genz-vibedose
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "modern-genz-vibedose"
      mode: "both"
```
