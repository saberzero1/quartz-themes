# Obsidian Windows 98 Edition

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/obsidian-windows-98-edition
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "obsidian-windows-98-edition"
        mode: "dark"
```
