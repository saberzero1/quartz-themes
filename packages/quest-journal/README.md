# Quest Journal

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: GPL-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/quest-journal
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "quest-journal"
        mode: "both"
```
