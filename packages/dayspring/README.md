# Dayspring

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: light
**License**: CC0-1.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/dayspring
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "dayspring"
      mode: "light"
```
