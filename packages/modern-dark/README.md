# Modern Dark

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: GPL-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/modern-dark
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "modern-dark"
        mode: "dark"
```
