# Evangelion

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark
**License**: CC0-1.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/evangelion
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "evangelion"
        mode: "dark"
```
