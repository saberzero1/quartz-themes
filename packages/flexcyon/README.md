# Flexcyon

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/flexcyon
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "flexcyon"
        mode: "both"
```

## Variants

- `flexcyon.tui`

```yaml
options:
  theme: "flexcyon"
  variation: "tui"
```
