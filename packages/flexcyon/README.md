# Flexcyon

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/flexcyon
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "flexcyon"
      mode: "both"
```

## Variants

- `flexcyon.tui`

```yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "flexcyon"
      variation: "tui"
      mode: "both"
```
