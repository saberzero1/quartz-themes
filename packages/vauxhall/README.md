# Vauxhall

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: MIT

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/vauxhall
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  transformers:
    - name: "@quartz-themes/core"
      options:
        theme: "vauxhall"
        mode: "both"
```

## Variants

- `vauxhall.blue`
- `vauxhall.magenta`
- `vauxhall.purple`
- `vauxhall.red`
- `vauxhall.teal`
- `vauxhall.white`

```yaml
options:
  theme: "vauxhall"
  variation: "blue"
```
