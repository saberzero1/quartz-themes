# Suddha

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: No SPDX ID Found

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/suddha
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "suddha"
      mode: "both"
```
