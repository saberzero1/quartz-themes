# Nott Dagr

Obsidian theme adapted for [Quartz](https://github.com/jackyzha0/quartz).

**Modes**: dark and light
**License**: Apache-2.0

## Installation

```bash
npm install @quartz-themes/core @quartz-themes/nott-dagr
```

## Usage

```yaml
# quartz.config.yaml
plugins:
  - source: "@quartz-themes/core"
    options:
      theme: "nott-dagr"
      mode: "both"
```
